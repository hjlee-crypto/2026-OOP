# 2026 객체지향프로그래밍 B반 기말 팀 프로젝트

B반 기말 팀 프로젝트 결과물을 제출하는 공간입니다.

## 제출 안내

- 제출 단위: 팀별 제출(팀 대표 1명)
- 제출 방법: Fork & Pull Request
- 제출 위치: `Final-Project/B-Class/`

각 팀은 지정된 팀 번호로 폴더를 직접 생성하고, 기존 프로젝트의 폴더 구조를 유지하여 결과물을 업로드합니다.

## 제출 폴더 구조 예시

```text
B-Class/
├── README.md
├── Team01/
├── Team02/
├── Team03/
└── ...
```

## Pull Request 제목 예시

```text
[B-Class][Team01] 프로젝트명
```
